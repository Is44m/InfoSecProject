About Post-Quantum Cryptography

What is Post-Quantum Cryptography?

Post-Quantum Cryptography (PQC) refers to cryptographic algorithms that are thought to be secure against an attack by a quantum computer. As quantum computers advance, they pose a significant threat to many of our current encryption methods.

In particular, Shor's algorithm running on a sufficiently powerful quantum computer can break most of the public-key cryptography currently in use, including RSA, ECC, and Diffie-Hellman.

Why Do We Need PQC?

While large-scale quantum computers don't yet exist, the risk they pose is significant:

  • Harvest Now, Decrypt Later: Adversaries can collect encrypted data now and decrypt it when quantum computers become available.
  • Long-term Security: Data that needs to remain secure for decades could be vulnerable.
  • Critical Infrastructure: Many security systems for critical infrastructure would need to be upgraded.

NIST PQC Standardization

The National Institute of Standards and Technology (NIST) initiated a process to standardize post-quantum cryptographic algorithms. This demo uses Kyber, one of the selected algorithms from this process.

Key Algorithms Selected by NIST:

  • CRYSTALS-Kyber: For general encryption (key establishment)
  • CRYSTALS-Dilithium: For digital signatures
  • FALCON: An alternative signature algorithm
  • SPHINCS+: A hash-based signature scheme

About This Demo

This demonstration implements Kyber, a lattice-based key encapsulation mechanism (KEM). It showcases:

  • Key generation - Creating quantum-resistant public and private keys
  • Encryption - Using the public key to secure messages
  • Decryption - Using the private key to read encrypted messages

Note: This is a simplified educational demonstration. Production systems would implement these algorithms as part of a larger cryptographic protocol with proper key management.
